## 📖 About Twenty

Twenty is a modern, open-source CRM built with cutting-edge technologies. It provides:

- **Customizable Objects & Fields** - Adapt the CRM to your business needs
- **Multiple Views** - Table, Kanban, filters, sorting, grouping
- **Workflow Automation** - Triggers and actions for process automation
- **Role-Based Permissions** - Fine-grained access control
- **Email & Calendar Integration** - Sync communications and events
- **Real-time Collaboration** - WebSocket-powered live updates
- **GraphQL API** - Modern, flexible API for integrations
- **Self-Hostable** - Full control over your data

## 🛠️ Technology Highlights

- **Frontend:** React 18, TypeScript, Recoil, Apollo Client, Emotion
- **Backend:** NestJS, GraphQL Yoga, TypeORM, BullMQ
- **Databases:** PostgreSQL, ClickHouse, Redis
- **Build Tools:** Nx, Vite, SWC
- **Testing:** Jest, React Testing Library, Storybook, Playwright
