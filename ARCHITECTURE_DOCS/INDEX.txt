💡 KEY CONCEPTS EXPLAINED

Workspace:          Isolated tenant/organization in Twenty
Metadata:           Object & field definitions (customizable schema)
Object Record:      Individual CRM record (Company, Contact, etc.)
GraphQL Query:      Request to fetch data from server
GraphQL Mutation:   Request to modify data on server
GraphQL Subscription: Real-time updates via WebSocket
Recoil Atom:        Single unit of state (like useState)
Recoil Selector:    Derived state computed from atoms
Apollo Cache:       Normalized storage of GraphQL responses
TwentyORM:          Workspace-aware ORM wrapper
TypeORM:            SQL database ORM
RBAC:              Role-Based Access Control
