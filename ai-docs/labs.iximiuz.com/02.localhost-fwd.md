Perfect! So you need to forward localhost ports to the primary network interface. Here's the exact solution for labs.iximiuz.com:

## Step-by-Step Solution

### 1. Find Your Primary Network Interface IP

```bash
# Get primary interface IP
ip addr show | grep "inet " | grep -v 127.0.0.1 | head -1 | awk '{print $2}' | cut -d/ -f1

# Or simpler
hostname -I | awk '{print $1}'
```

Let's say it returns `10.0.0.5` (example).

### 2. Forward Ports Using `socat`

```bash
# Install socat if not available
sudo apt-get update && sudo apt-get install -y socat

# Forward frontend (localhost:3001 → primary interface:3001)
socat TCP-LISTEN:3001,fork,reuseaddr,bind=0.0.0.0 TCP:127.0.0.1:3001 &

# Forward backend (localhost:3000 → primary interface:3000)
socat TCP-LISTEN:3000,fork,reuseaddr,bind=0.0.0.0 TCP:127.0.0.1:3000 &
```

### 3. Create a Persistent Forwarding Script

Create `forward-ports.sh`:

```bash
#!/bin/bash

# Kill existing socat processes for these ports
pkill -f "socat.*:3001"
pkill -f "socat.*:3000"

echo "Starting port forwarding..."

# Forward frontend port 3001
socat TCP-LISTEN:3001,fork,reuseaddr,bind=0.0.0.0 TCP:127.0.0.1:3001 > /tmp/forward-3001.log 2>&1 &
FRONTEND_PID=$!
echo "Frontend forwarding started (PID: $FRONTEND_PID)"

# Forward backend port 3000
socat TCP-LISTEN:3000,fork,reuseaddr,bind=0.0.0.0 TCP:127.0.0.1:3000 > /tmp/forward-3000.log 2>&1 &
BACKEND_PID=$!
echo "Backend forwarding started (PID: $BACKEND_PID)"

# Save PIDs for later
echo $FRONTEND_PID > /tmp/forward-3001.pid
echo $BACKEND_PID > /tmp/forward-3000.pid

echo ""
echo "Port forwarding active:"
echo "  localhost:3001 → 0.0.0.0:3001 (PID: $FRONTEND_PID)"
echo "  localhost:3000 → 0.0.0.0:3000 (PID: $BACKEND_PID)"
echo ""
echo "To stop: kill $FRONTEND_PID $BACKEND_PID"
echo "Or run: ./stop-forwarding.sh"
```

Create `stop-forwarding.sh`:

```bash
#!/bin/bash

echo "Stopping port forwarding..."

if [ -f /tmp/forward-3001.pid ]; then
    kill $(cat /tmp/forward-3001.pid) 2>/dev/null
    rm /tmp/forward-3001.pid
    echo "Stopped frontend forwarding"
fi

if [ -f /tmp/forward-3000.pid ]; then
    kill $(cat /tmp/forward-3000.pid) 2>/dev/null
    rm /tmp/forward-3000.pid
    echo "Stopped backend forwarding"
fi

echo "Done!"
```

Make them executable:

```bash
chmod +x forward-ports.sh stop-forwarding.sh
```

### 4. Start Everything in the Right Order

```bash
# 1. Start port forwarding FIRST
./forward-ports.sh

# 2. Verify forwarding is working
netstat -tlnp | grep -E ':(3000|3001)'
# Should show processes listening on 0.0.0.0:3000 and 0.0.0.0:3001

# 3. Start backend (it will bind to localhost:3000)
cd packages/twenty-server
yarn start:dev

# 4. In another terminal, start frontend (it will bind to localhost:3001)
cd packages/twenty-front
yarn start

# 5. Now expose ports in labs.iximiuz.com UI
# Expose port 3001 (frontend)
# Expose port 3000 (backend)
```

### 5. Verify It's Working

```bash
# Check that socat is forwarding
ps aux | grep socat

# Check listening ports
ss -tlnp | grep -E ':(3000|3001)'

# You should see:
# 0.0.0.0:3000  (socat forwarding)
# 127.0.0.1:3000 (your backend)
# 0.0.0.0:3001  (socat forwarding)
# 127.0.0.1:3001 (your frontend)

# Test locally
curl http://localhost:3001
curl http://localhost:3000/graphql
```

## Troubleshooting

### If socat fails with "Address already in use":
```bash
# Find what's using the port
sudo lsof -i :3001
sudo lsof -i :3000

# Kill the process
kill -9 <PID>

# Or kill all socat processes
pkill socat
```

### If forwarding stops working:
```bash
# Check socat logs
tail -f /tmp/forward-3001.log
tail -f /tmp/forward-3000.log

# Restart forwarding
./stop-forwarding.sh
./forward-ports.sh
```

### If labs.iximiuz.com can't reach the ports:
```bash
# Make sure services are running
curl http://localhost:3001
curl http://localhost:3000/graphql

# Make sure socat is forwarding
netstat -tlnp | grep -E ':(3000|3001)'

# Should show 0.0.0.0:3000 and 0.0.0.0:3001
```
