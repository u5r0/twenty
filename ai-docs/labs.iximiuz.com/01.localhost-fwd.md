I'll help you set up port forwarding to expose your localhost services through labs.iximiuz.com. Here are several methods:

## Method 1: Using `socat` (Simple TCP Forwarding)

### Install socat
```bash
# Check if installed
which socat

# Install if needed
sudo apt-get update && sudo apt-get install -y socat
```

### Forward Frontend (Port 3001)
```bash
# Forward all traffic from 0.0.0.0:3001 to localhost:3001
socat TCP-LISTEN:3001,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3001
```

### Forward Backend (Port 3000)
```bash
# In another terminal
socat TCP-LISTEN:3000,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3000
```

### Run Both in Background
```bash
# Frontend
socat TCP-LISTEN:3001,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3001 &

# Backend
socat TCP-LISTEN:3000,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3000 &

# Check running processes
jobs
```

## Method 3: Using `nginx` as Reverse Proxy (More Robust)

### Install nginx
```bash
sudo apt-get update && sudo apt-get install -y nginx
```

### Create nginx config
```bash
sudo tee /etc/nginx/sites-available/twenty <<'EOF'
server {
    listen 80;
    server_name _;

    # Frontend
    location / {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Backend API
    location /graphql {
        proxy_pass http://localhost:3000/graphql;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /metadata {
        proxy_pass http://localhost:3000/metadata;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /rest {
        proxy_pass http://localhost:3000/rest;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
EOF

# Enable the site
sudo ln -sf /etc/nginx/sites-available/twenty /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default

# Test and reload
sudo nginx -t
sudo systemctl reload nginx
```

## Method 4: Using `iptables` (Kernel-level Forwarding)

```bash
# Enable IP forwarding
sudo sysctl -w net.ipv4.ip_forward=1

# Forward port 3001
sudo iptables -t nat -A PREROUTING -p tcp --dport 3001 -j REDIRECT --to-port 3001
sudo iptables -A INPUT -p tcp --dport 3001 -j ACCEPT

# Forward port 3000
sudo iptables -t nat -A PREROUTING -p tcp --dport 3000 -j REDIRECT --to-port 3000
sudo iptables -A INPUT -p tcp --dport 3000 -j ACCEPT

# Save rules
sudo iptables-save | sudo tee /etc/iptables/rules.v4
```

## Method 5: Using `nc` (netcat) - Quick & Dirty

```bash
# Frontend
while true; do nc -l -p 3001 -c "nc localhost 3001"; done &

# Backend
while true; do nc -l -p 3000 -c "nc localhost 3000"; done &
```

## Recommended: Complete Setup Script

Create a file `setup-forwarding.sh`:

```bash
#!/bin/bash

echo "Setting up port forwarding for Twenty CRM..."

# Kill existing socat processes
pkill -f "socat.*3001"
pkill -f "socat.*3000"

# Forward frontend (3001)
echo "Forwarding frontend on port 3001..."
socat TCP-LISTEN:3001,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3001 > /tmp/socat-3001.log 2>&1 &
FRONTEND_PID=$!

# Forward backend (3000)
echo "Forwarding backend on port 3000..."
socat TCP-LISTEN:3000,fork,reuseaddr,bind=0.0.0.0 TCP:localhost:3000 > /tmp/socat-3000.log 2>&1 &
BACKEND_PID=$!

echo "Port forwarding started!"
echo "Frontend PID: $FRONTEND_PID"
echo "Backend PID: $BACKEND_PID"
echo ""
echo "To stop forwarding, run:"
echo "  kill $FRONTEND_PID $BACKEND_PID"
echo ""
echo "Logs:"
echo "  Frontend: tail -f /tmp/socat-3001.log"
echo "  Backend: tail -f /tmp/socat-3000.log"
```

Make it executable and run:
```bash
chmod +x setup-forwarding.sh
./setup-forwarding.sh
```

## Troubleshooting

### If ports are blocked:
```bash
# Check firewall
sudo ufw status
sudo ufw allow 3000
sudo ufw allow 3001

# Or disable temporarily
sudo ufw disable
```

### If socat isn't working:
```bash
